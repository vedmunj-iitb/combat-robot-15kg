# 15 kg Combat Robot (Horizontal Spinner)

A 15 kg combat robot with a titanium horizontal spinner, built for Robowars.

Robowars, Techfest, IIT Bombay, Dec 2024. I was the Team Lead of a 6-member team.

## What I did

I led the 6-member team that designed and built the robot. The team competed in the Techfest
Robowars 15 kg category at IIT Bombay.

## The robot

| | |
|---|---|
| Weight class | 15 kg |
| Weapon | horizontal spinner, titanium |
| Weapon motor | BLDC |
| Drive | geared DC motors |
| Battery | 28 V |
| Frame | aluminium beams |
| Outer panels | stainless steel |

## Result

The team was selected among the top 5 teams.
